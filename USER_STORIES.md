# User Stories

## 1. Registration

As a new user, I want to create an account using my username, email, and password.

## 2. Login

As a registered user, I want to log in with my email and password.

## 3. Home

As a user, I want to see available content on the home screen.

## 4. Details

As a user, I want to open an item and view its detailed information.

## 5. Favorites

As a user, I want to save items to my favorites.

## 6. Persistence

As a user, I want my favorites to remain available after restarting the application.

## 7. API

As a user, I want the application to retrieve data from an external API.

## 8. Settings

As a user, I want to access settings and configure application preferences.

## 9. Notifications

As a user, I want to configure notifications and receive notification alerts.
